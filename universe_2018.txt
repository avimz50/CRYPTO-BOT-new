# Crypto top-100 by market cap, as it stood around 1 January 2018.
#
# WHY THIS FILE EXISTS
#   The whole point of the SIGNUM test is that a universe chosen TODAY is
#   already a list of winners. This file freezes the universe at the start
#   of the backtest window instead, so the coins that later died are still
#   in the test and still able to lose money.
#
# HOW IT IS USED
#   A ticker here that cannot be fetched is NOT skipped. It is recorded as a
#   delisting and priced at a total loss from its last available bar.
#   Silently dropping unfetchable tickers is exactly the bias being measured.
#
# ACCURACY CAVEAT — READ THIS
#   This list is reconstructed from memory of the January 2018 rankings and
#   is approximate: the tail beyond roughly the top 40 is the least reliable,
#   and a few tickers have been reused by unrelated projects since.
#   It is good enough to size the bias, not to publish. To do this properly,
#   replace this file with a real dated snapshot (CoinGecko and
#   coinmarketcap both expose historical rankings) and re-run. The script
#   reads whatever is here, so swapping the file is the only step needed.
#
# One ticker per line. Blank lines and # comments are ignored.
