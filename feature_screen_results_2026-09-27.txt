HOW TO READ THIS
====================================================================================================
  r is the correlation between the feature (known at decision time)
  and the forward return (LONG) or its negative (SHORT). A feature
  only deserves a place in a new scorer if the SAME direction shows
  |t| > ~2.5 in BOTH train and test, with the SAME sign. A feature
  that only works in one window is fitting noise.
  Windows overlap (hourly sampling, up to 2h horizon), so treat t
  as a screening heuristic, not a final significance test.
