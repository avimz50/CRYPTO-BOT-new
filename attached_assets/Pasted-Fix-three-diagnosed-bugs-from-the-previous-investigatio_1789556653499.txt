currently only runs inside track_trades(), which is only called when
active_trades is non-empty. When active_trades becomes empty (no open
positions), the daily reset is never reached, so a stale loss value from
a prior day can remain active and block all new entries (Swing/Breakout/
Scalp/Research) via the -$15 circuit breaker even on a new day.
Fix: make the daily reset time-based (keyed off calendar date, e.g.
compare current date to last-reset date) and run it unconditionally on
each scan/heartbeat cycle, independent of whether there are active
trades. Show me exactly where this reset is checked and fixed.
